# Figure generation

This folder contains the data workbooks and Python scripts which generate the final figures in the paper.

## Main Figure Script

`supply_demand_figures.py` is a self-contained script for generating the final supply-and-demand attribute figures. The corresponding input workbooks in this folder are:

- `Supply-side factor summary.xlsx`
- `VOT.xlsx`

The script does not import any Python files from the parent directory.

It generates figures for the following nine attributes:

1. Access and egress time
2. Cost
3. Speed
4. Capacity
5. Altitude
6. Range
7. Time spent at the vertiport
8. Value of time (VOT)
9. Vertiport density per thousand square kilometres

Two SVG versions are generated for every attribute:

- `final_figures/without_numbers/`: figures without paper numbers.
- `final_figures/with_numbers/`: figures with a paper number above every bar or point.

The script also generates:

- `final_figures/figure_manifest.csv`: plotting and quality-control information, including the number of plotted rows, bar-overlap checks, bar width, point size, and y-axis ranges.
- `final_figures/author_number_mapping.csv`: the correspondence between figure numbers, authors, publication years, and countries or regions.

## Paper Numbering Rule

A paper is identified by the combination of `Author + Year`.

If one paper occupies multiple Excel rows or produces multiple bars or points, all of those marks receive the same number. Papers are ordered by publication year from newest to oldest. Papers within the same year follow their original row order in the corresponding worksheet.

## Python Environment

### Supported environment

- Operating system: Windows 10 or Windows 11
- Python: 3.10 or later
- Recommended Python version: Python 3.12

The script was tested successfully with:

| Component | Tested version |
| --- | ---: |
| Python | 3.12.6 |
| matplotlib | 3.9.2 |
| numpy | 1.26.4 |
| openpyxl | 3.1.5 |
| pandas | 2.2.3 |

### Required Python libraries

The main figure script requires:

- `matplotlib`: creates the bar, scatter, broken-axis, legend, and SVG output.
- `numpy`: calculates point and bar positions and performs numerical checks.
- `pandas`: reads the Excel worksheets, prepares the plotting data, and writes the CSV reports.
- `openpyxl`: serves as the Excel engine used by pandas to read `.xlsx` files.

## Running the Main Figure Script

From the `Submit` folder, run:

```powershell
python supply_demand_figures.py
```

The default output location is:

```text
Submit\final_figures
```

To use a different output folder, run:

```powershell
python supply_demand_figures.py --output-dir "D:\output\TRB_figures"
```

The input paths are resolved relative to `supply_demand_figures.py`, so the script can also be launched from another working directory.

## Input Workbook Descriptions

### Supply-side factor summary.xlsx

This workbook contains the supply-side attributes used in the main figures, including access and egress time, travel cost, vertiport information, time spent at vertiports, speed, capacity, altitude, and range. `supply_demand_figures.py` reads the author, year, use type, and minimum, maximum, or single-value fields from the relevant worksheets.

### VOT.xlsx

This workbook contains the value-of-time data and related classifications. The main figure script reads the `VOT_processed` worksheet to generate the VOT figure.

### Sign of socio-economic factors.xlsx

This workbook contains the summarized data used to plot **Positivity/Negativity of socio-economic, safety and travel habit factors**. It records the number of papers reporting positive, negative, statistically insignificant, or mixed influences.

The existing `odd_ratio.py` script uses this workbook to generate `Odd.svg`. This figure is separate from the nine attribute figures generated by `supply_demand_figures.py`.

### Socio-demographic and attitudinal factors.xlsx

This workbook records the numbers of papers covering socio-demographic factors, travel habits, and safety, together with the reported direction of their effects on UAM acceptance. Its worksheets contain information for factors such as age, gender, income, employment, education, safety, vehicle ownership, air-travel frequency, current travel patterns, and other travel habits.
